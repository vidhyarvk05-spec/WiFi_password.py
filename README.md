# 🔐 WiFi Password Security Auditor

A professional hacker-style cybersecurity project developed using **Python**, **Tkinter**, and **Regex** that checks the strength and security level of WiFi passwords.

This application analyzes passwords based on:
- Password length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

The project also includes:
- Animated hacker UI
- Password visibility toggle
- Animated password strength bar
- Cybersecurity-themed interface

---

# 📌 Project Overview

The **WiFi Password Security Auditor** helps users evaluate the security of their WiFi passwords.

Weak passwords are one of the main reasons for:
- WiFi hacking
- Unauthorized access
- Data theft
- Network vulnerability

This tool educates users by showing whether a password is:
- Weak
- Medium
- Strong
